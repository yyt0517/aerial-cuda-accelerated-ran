[manifest.json](manifest.json)逐文件记录原始来源、大小和SHA-256。单seed选择用1秒切换窗口；最新五seed验证用连续信道时钟、各策略稳定化后10秒测量，二者不混池统计。比例固定90/100，不因五seed结果重新调节。

[独立复核](five_seed/independent_review.json)重算8项主要指标的均值、样本SD与配对区间，核对5760328条成熟包记录、逐UE汇总、及时交付分布及10份原始轨迹压缩档案。`five_seed/code/`保留实际策略、入口和分析源码快照；这些快照仍依赖配置中列明的研究运行时。

根目录 `manifest.json` 覆盖选型、固定下界和五seed的32份快照；联合修复另见 `tb_joint_repair/sha256.json`、`input_manifest.json` 和各轮协议，不能把根清单当作整个日期目录的文件清单。后续PHY补表见[10-29索引](../2026-10-29/README.md)。首轮报告中GPU不可见的描述仅指当时执行环境；后续原生试验已使用现有CUDA容器，不能据旧报告推断宿主机无GPU。
