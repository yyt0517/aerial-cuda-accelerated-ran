七小区有界紧急度DA：lambda=0.1，beta=0.98
=========================================

冻结原七小区仿真器、物理模型、业务、输入、FIFO口径、邻域和搜索停止规则。
新权重是原有界缺口权重乘以(1+0.1*HOL_urgency)，再归一化。
每个当前状态计算DPLS、原始PFQ起点的新目标搜索、DPLS终点起点的新目标搜索。
后两个分支的完整搜索和最终候选打分都使用新权重；DPLS保留原权重提供基准。
第三分支复用此前已审计的强制起点库，仍保留原始PFQ计划出队90%下界。

最终仅在总预期成功服务>=0.98*当前状态DPLS预期成功服务的候选中择优。
保护线不并入分支内每轮搜索。精确同分优先新冷启动、DPLS起点新搜索、DPLS。
仅执行最终动作并更新一个闭环状态。该单步保证不等于长期时延保证。

每seed测量10秒；对照复用原DPLS、原DA和原三分支DA九条轨迹。
保存4001/8001/18001/28000时隙，独立完整邻域核验三个分支。
