# Stage-B 当前项目进展

更新至 **2026-10-29**。当前有效算法为 **PFQ＋CTBS＋因果服务缺口加权物理局部搜索，出队下界 ρ=0.90**（下称 DPLS）。boundary 与 uniform 场景的五 seed 长窗口对照均已完成；神经路径完成原生闭环、缓存降本、前缀验证及残差学习探索，但质量门槛尚未全部通过，仍处于研究阶段。

## 1. 当前有效版本与交付范围

算法 ID 为 `pfq_ctbs_deficit_search_rho090_20261027`。执行链为 **fresh PFQ → CTBS 裁剪 → 因果服务缺口权重 → 完整物理局部搜索**，每个 TTI 的下界为 `ceil(0.90 × 本臂当前 PFQ+CTBS 草案总出队字节)`。不加载 BC actor 或定向协调器，也不读取另一条轨迹的下界。该比例约束草案出队预算，不保证实际成功吞吐最多损失 10%。

[算法注册表](../training/stageb_hgraph/current_algorithm.json)、[启动入口](../cuMAC/scripts/run_stageB_current_algorithm.sh)及[配置与指标口径](current_stageB_effective_configuration.md)共同界定版本。启动入口目前对应 boundary 场景；uniform 使用单独冻结的研究 runner。

主仓库保存文档、小型证据、研究源码快照及当前版本入口。完整运行仍依赖本地 `.worktrees/pfq-independent-reuse-actor`、`deliverables/`、研究包和 CUDA 容器；专用运行时尚未整体合入，克隆仓库不能直接重放全部实验。旧报告中的 `current`、`legacy_current` 按原始日期与物理实现解释，不能自动替换为当前版本。

## 4. 下一步与晋级条件

[10-29 搜索收益诊断](evidence/2026-10-29/tb_search_gain_analysis/report.txt)只读取冻结候选树，没有新增训练、PHY 评分或原生轨迹。新提议器虽增加高收益集合召回，覆盖损失却由 24.21 增至 32.56，总候选损失由 42.73 增至 50.41（代理 R 单位）；当前补全 R 领先者在 1283 组已展开前缀中有 294 组（22.9%）被已观察的继续收益反超。仅比较当前可接受前缀时仍有 166/586 组（28.3%）翻转。未展开节点未来值未知，不记为 0。

下一轮建议按以下顺序冻结最小实验，尚未实施：

1. 消融“精确/预测评分混排”，保持 actor、beam、quota 和总预算一致，验证其对前缀选择的实际影响。
2. 验证单 PRG 活动模式分解及各小区 (R,J,D) 非支配解合并，先与完整组合穷举逐项核对，再扩展块；其分解条件依赖当前 PHY 的活动 mask 耦合模型。
3. 对训练 seed 的自身访问前缀做显式计费的 1–2 步继续搜索；先证明等总成本收益，再训练未来价值和近最优候选目标。下一轮预声明 regret@K 等指标，既有 95% 召回门槛仍保持失败判定。

新方法先通过完整搜索的最终 R/J、配对胜率、最差 seed 和成本检查，再进入原生闭环。原生晋级需相对明确冻结的 ρ0.90 物理对照逐 seed 满足：完整包 payload ≥99.5%、TTL 增量 ≤0.1 pp、平均/P95 成功包时延不高于对照、UE P5 不低于对照，并事前声明 UE payload 下降 >2% 的数量上限。当前 J 搜索与同风险 R 搜索分别报告。新 seed 最终测试留待质量门槛满足后开展。
